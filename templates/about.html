About HR Employee Attrition AI System

Project Overview

The HR Employee Attrition AI System is an end-to-end machine learning web application designed to analyze workplace demographics, job satisfaction indicators, compensation data, and work conditions to predict employee attrition probability.

Key Objectives

  • Identify key drivers behind employee turnover and resignation trends.
  • Provide actionable risk scores to help HR teams implement proactive retention strategies.
  • Automate data preprocessing including imputation, encoding, and standardization.
  • Evaluate multiple supervised ML models (Logistic Regression, Decision Trees, Random Forest, KNN, XGBoost).
  • Offer an intuitive web dashboard with left-sidebar navigation for seamless workflow exploration.

Technologies & Stack

  • Language: Python 3
  • Web Framework: Flask
  • Data Science & Machine Learning: Pandas, NumPy, Scikit-learn, Seaborn, Matplotlib
  • Frontend Design: HTML5, Vanilla CSS3 (Custom Design System, Responsive Flexbox & Grid)

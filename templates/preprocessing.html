🔧 HR Data Preprocessing Pipeline

Comprehensive data transformation pipeline applied to prepare HR_Employee_Attrition_raw.csv for machine learning model training.

1. Missing Value Imputation

Applied Deletion, Mean/Median Imputation, Linear Regression Model Imputer, and MissingIndicator feature flags.

2. Categorical Encoding

Implemented One-Hot Encoding, Ordinal Encoding, Target Encoding (based on Attrition rate), and Embedding Encoders.

3. Feature Scaling

Applied StandardScaler (Z-score standardization), MinMaxScaler (0-1 range), and L2 Normalizer across all 15 numerical features.

4. Text Normalization

Cleaned whitespace formatting, stripped trailing spaces, and normalized text categories for Department, JobRole, and EducationField.
